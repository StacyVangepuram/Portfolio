# 💼 Stacy Vangepuram - Personal Portfolio Website

Welcome to the repository for my personal portfolio website! This responsive, cleanly designed site is a central hub to showcase my skills, educational background, professional experience, and the various software development projects I've worked on.

## 🌟 Overview

As a passionate developer and CS student, I've built this portfolio to highlight my journey in technology, problem-solving, and continuous learning. 

You can view the live repository and my other projects on my GitHub profile: [@StacyVangepuram](https://github.com/StacyVangepuram)

## 🛠️ Built With

*   **HTML5:** Semantic and accessible web structure.
*   **CSS3:** Modern styling, flexbox/grid layouts, and responsive design for all screen sizes.
*   **Vanilla JavaScript:** Interactive elements and smooth scrolling.
*   **FontAwesome:** Scalable vector icons.
*   **Google Fonts:** Modern typography (Poppins).

## 🗂️ Sections

*   **Home:** Introduction and quick links to my socials.
*   **Skills:** A rundown of my technical stack, including Web Development, Python, Streamlit, and NLP integration.
*   **Projects:** Links to my key projects (Weather App, CareerNexus, Plant Disease Detection, etc.) and their respective repositories.
*   **Education:** Details regarding my academic background in Computer Science.
*   **Experience:** Highlights of my internships in AI and software development, along with my certificates.
*   **Contact:** A direct form powered by Formspree for easy communication.

## 🚀 Running Locally

To run this project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/StacyVangepuram/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your web browser of choice.
